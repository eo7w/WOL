# واجهة التداول العربية

ملفات المصدر والأصول الخاصة بواجهة التداول العربية، كما كانت في المشروع الأصلي. لم تُعدَّل الواجهة أو يُعَد نشر الموقع أثناء رفع هذه النسخة.

## التشغيل محليًا

يتطلب المشروع Node.js وnpm، وPython 3 لأمر خادم المعاينة أدناه.

```bash
npm ci
npm run build
python3 -m http.server 8080 --directory public
```

افتح `http://localhost:8080`. ويمكن عرض النسخة المجمعة الموجودة أصلًا في `public` دون إعادة البناء.

## الملفات

- `src/`: مكونات React والمنطق والتنسيقات المصدرية.
- `public/`: الصفحة والملفات المجمعة والصور والشعارات المطلوبة للتشغيل.
- `build.mjs`: تجميع JavaScript وTailwind وتحديث إصدار الروابط في الصفحة.
- `package.json` و`package-lock.json`: الاعتماديات وأمر البناء.

يُشغّل خادم المعاينة من `public` لأن روابط الأصول تبدأ من جذر الموقع. يحتوي البناء على ملف CSS مجمع موجود في `public/app.css`، لذا يجب إبقاؤه ضمن المشروع.

بعض بيانات الواجهة والرصيد والموافقات محاكاة محلية وليست نظام حسابات أو دفع أو مصادقة إنتاجية. بيانات السوق تعتمد على خدمات خارجية معرفة في ملفات المصدر، وقد تتأثر بتوافر هذه الخدمات.

لم تُدرج مفاتيح API أو ملفات `.env` أو ملفات المطالبة أو إعدادات النشر الخاصة أو `node_modules`. لا توجد خطوة نشر تلقائي ضمن هذه الإضافة. أُبقي ملف `x` السابق دون تغيير.
